# JEE Swipe — iPhone/iPad PWA prototype

This is a browser-based version of the JEE Swipe prototype.

Features:
- One MCQ per screen
- Four options
- Immediate correct/wrong feedback
- Vertical swipe/scroll feed
- All / Physics / Chemistry / Math filters
- Randomized question order
- Offline caching after the PWA has been loaded once
- Dark futuristic UI
- No coding is required to USE the app

## Important iPhone/iPad note

A PWA's Home Screen installation and service-worker offline mode normally require the files to be served from an HTTPS website. Opening `index.html` directly from the Files app is useful for previewing, but it is not the same as installing the app.

Once hosted on HTTPS:
1. Open the site in Safari.
2. Tap Share.
3. Choose "Add to Home Screen".
4. Open JEE Swipe from the Home Screen.

The question bank in this prototype is intentionally small. The next stage is to replace it with the full JEE Main + JEE Advanced question bank.
